
SUN TEMPLE MOD - VR Navigation Experiments

By Jordi Batalle (PatimPatam)

----------------------------------------------------------------------------------------------


CONTROLS
--------


LEFT HYDRA

- Reset HMD = Left Start


- Activate Head-Based Translation = Button 1 / Button 2 / Shoulder Button

- Classic Move = Left Thumbstick


RIGHT HYDRA

- Menu = Right Start

- Interact with menus = Right Trigger


- Activate Hand-Based Rotation = Button 1 / Button 2 / Shoulder Button

- Classic Turn = Right Thumbstick



XBOX GAMEPAD:

- Reset HMD = Back

- Menu = Start

- Interact with menus = Right Trigger


- Activate Head-Based Translation = DPAD Up / DPAD Down / Shoulder Button

- Activate Head-Based Rotation (Direct) = Button A / Shoulder Button

- Activate Head-Based Rotation (Standard) = Button X / Button Y


- Classic Move = Left Thumbstick

- Classic Turn = Right Thumbstick



KEYBOARD:

- Reset HMD = R

- Menu = ENTER

- Exit = Esc


- Enable 1-Button Mode = 1

- Disable 1-Button Mode = 2


- Increase Turn Sensitivity = Page Up

- Decrease Turn Sensitivity = Page Down

- Increase Move Sensitivity = Home

- Decrease Move Sensitivity = End
